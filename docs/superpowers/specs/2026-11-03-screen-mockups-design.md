# 세이프티 리그 화면 시안 4종 설계

- 작성일: 2026-11-03
- 대상: 11/15 공모전 제출용 화면 시안 4종 (주행 결과 카드, 리그 순위, 주행 중 화면, 주간 리포트)
- 브레인스토밍 시안 파일: 저장소 상위 폴더의 `.superpowers/brainstorm/1402-1793622891/content/` (저장소 밖, 참고용)

## 1. 의도

심사위원이 시안 4장을 넘겨 볼 때 "안전운전이 이렇게 재미있을 수 있구나"라고 느끼게 하는 것이 목표다.
기존 안전운전 캠페인은 정적이고 훈계조라 재미없다. 세이프티 리그는 듀오링고처럼 **연속 기록과 리그 승급**을
재미의 중심에 두고, 안전운전에 **경쟁**을 더해 하고 싶게 만든다.

감정의 흐름:
- 잘 달린 날 주차하면: 게임에서 이긴 것처럼 짜릿하고 뿌듯하다.
- 못 달린 날: 혼나는 느낌이 아니라, 아깝게 진 판처럼 "한 판 더" 하고 싶다.

시안은 그림으로 제출하지만, 11/23부터 앱을 구현할 때 같은 디자인(색·글꼴·부품·배치)을 그대로 옮긴다.
시안이 곧 앱의 설계도다.

## 2. 목표 / 비목표 / 실패 조건

목표
- 4개 화면이 하나의 세계관("레이싱 중계")으로 보인다.
- 결과 카드는 이긴 날과 아쉬운 날 두 버전을 보여 준다.
- 시안 안의 숫자가 서로 맞는다 (같은 운전자, 같은 시즌).

비목표
- 시안 단계에서 실제 동작하는 앱이나 애니메이션 구현.
- 4종 외 화면(설정, 온보딩, 친구 추가 등).

실패 조건 (기술적으로 돌아가도 실패)
- 훈계하거나 겁주는 느낌: 교통사고 통계, 빨간 경고 목록, 감점 나열.
- 운전 중 시선을 끄는 주행 중 화면: 점수·순위·감점 표시, 계속 움직이는 애니메이션.
- 시안끼리 숫자가 어긋남.
- 실명·연락처·이메일·소속 노출 (02 작품 소개·시안·GitHub 규칙).

## 3. 고정 제약

- 화면 크기 1280×720 (차량 디스플레이).
- 주행 중: CarUxRestrictionsManager 준수, 점수 화면 금지, 백그라운드 수집만.
- 결과 카드는 GEAR_SELECTION이 P로 바뀔 때 표시.
- 점수 배점: 부드러움 30 · 매너 25 · 에코 20 · 안전 기본기 15 · 꾸준함 10.
- 공정성: 10km당 환산, 3km 미만 트립 제외, EV/내연기관 리그 분리.
- 리그 순위 데이터는 시연용 가상 운전자.

## 4. 이번 브레인스토밍에서 정한 규칙

- 연속 안전 주행: 트립 점수 **70점 이상**이면 이어지고, 미만이면 끊긴다 (70점은 임시값, 추후 확정).
  **운전하지 않은 날은 건너뛴다** (기록이 끊기지도, 늘지도 않음). 운전을 부추기지 않기 위해서다.
  하루에 여러 번 달리면 그날의 트립 중 하나라도 70점 미만이면 끊긴다 (빌더 판단으로 둔 기본값, 앱 구현 때 재확인).
- 리그 승급·강등: 월간 시즌이 끝날 때 같은 티어 안에서 **상위 30% 승급, 하위 30% 강등**, 나머지 40% 잔류.
  시즌 중에는 티어가 바뀌지 않는다.
- 티어: 브론즈 · 실버 · 골드 · 플래티넘 · 다이아.
- 닉네임: 운전자가 직접 정한다. 순위표에서 다른 운전자는 각자 정한 닉네임으로 보인다.
  내 줄은 한눈에 찾도록 "나"로 표시한다 (빌더 판단). 닉네임 설정 화면은 시안 4종 범위 밖이다.

조언은 "피트 보드"(팀이 드라이버에게 들어 보이는 작전판)로 부른다.

## 6. 화면별 설계

### 6-1. 주행 결과 카드: 이긴 날

- 왼쪽: "아이오닉 5 리그 · 오늘의 레이스 종료", 큰 점수 **92점**.
  점수 아래 빨간 띠에 순위 상승(▲3)과 승급 라인까지 남은 거리를 보여 준다.
  (시안 v1의 "플래티넘 승급 / 골드 졸업" 문구는 시즌 끝 승급 규칙과 어긋나므로 쓰지 않는다.)
- 왼쪽 아래: 연속 안전 주행 13일, 주행 거리 18.4km.
- 오른쪽: 순위 타워. 내 위 2명, 나(노란 줄), 아래 3명. 오늘 제친 사람에게 빨간 "추월" 표시.
  바로 위 사람과의 점수 차 문구("0.3점 차, 다음 주행에서 따라잡을 수 있어요").
- 오른쪽 끝에 얇은 체커기 띠.

### 6-2. 주행 결과 카드: 아쉬운 날

- 큰 점수 **64점**을 회색으로. 축하 띠 없음.
- 피트 보드(노란 판): "다음 주행 작전" + 고칠 것 하나만 ("차선 바꿀 때 깜빡이부터 켜기"),
  근거 한 줄("오늘 깜빡이 없이 차선 변경 4회")과 기대 효과("매너 +9점 가능").
- 연속 기록: "13일 → 0일" 회색, 아래 노란 글씨 "다음 주행 70점이면 1일부터 다시".
- 순위 타워: 나 P126 ▼1. 나를 제친 사람에게 노란 점선 테두리와 "목표" 표시, "0.4점 차, 한 번만 잘 달리면 되찾아요".

### 6-3. 리그 순위

- 위: "11월 시즌 · 골드 리그 · 21일 남음", 오른쪽에 기울어진 탭 (차종 / 지역 / 친구).
- 왼쪽 위: 내 순위 **P125**를 가장 크게, "골드 리그 397명 중", 노란 띠 "승급 라인까지 6계단 · 0.9점",
  티어 5칸 중 골드 강조.
- 왼쪽 아래: 안전운전 효용 두 칸.
  - 개인: "안전운전으로 내가 아낀 돈 ₩8,400 (이번 달)".
  - 리그 전체: "우리 리그가 함께 줄인 급제동 3,120회 (이번 주, 지난주보다 12% 적게)".
- 오른쪽: 순위 타워 (P1, P2 … P118, P119, 노란 점선 승급 라인 "상위 30%", P124, 나 P125, P126 … 빨간 점선 강등 라인 "하위 30%").
- 교통사고 통계는 넣지 않는다 (겁주기 방식이고, 실시간 공개 데이터 출처가 없음).

### 6-4. 주행 중 화면

- "주행 기록 중" 표시, 큰 제목 "오늘의 레이스 진행 중", "결과는 주차하면 공개돼요".
- 아래 트랙: 1km마다 한 칸씩 노랗게 차오름.
  - 내비 목적지가 있으면 목적지 거리로 트랙 길이를 정하고 끝에 체커기 (NaviHelper).
  - 목적지가 없으면 체커기 없이 칸만 늘어남.
  - 앞 3칸 위에 "3km부터 기록 인정".
- 트랙 위 작은 자동차 아이콘이 1km마다 한 칸씩 이동 (계속 움직이는 애니메이션 아님).
- 배경: 내 차종 옆모습 선 실루엣, 투명도 약 15~18%, 글자와 겹치지 않는 트랙 위 오른쪽.
  실루엣은 실제 제원(아이오닉 5: 길이 4,635 / 휠베이스 3,000 / 높이 1,605mm) 비율과 Z 캐릭터 라인으로 그린다.
  사진은 쓰지 않는다 (업로드 기능 필요, 이미지 사용권 문제).
- 오른쪽 아래 노란 글씨 "70점 넘기면 연속 13일째". 점수·순위·감점은 표시하지 않는다.

### 6-5. 주간 리포트

- 위: "11월 2주차 리포트 · 11.03 ~ 11.09 · 주행 6일".
- 왼쪽: 주간 평균 **88.8점**, 노란 띠 "지난주보다 +3.1", "지난주 85.7".
  요일별 점수 막대 (월 84, 화 88, 수 휴식, 목 90, 금 92, 토 86, 일 93), 가장 높은 날(일)만 노랑.
- 오른쪽: 포지션 차트. 요일별 순위 선 (월 P131 → 화·수 P130 → 목 P128 → 금 P125 → 토 P126 → 일 P125),
  위에 노란 점선 승급 라인 P119, 가장 많이 오른 날(금 +3) 강조. 머리글 "P131 → P125 ▲6".
- 아래 한 줄 피트 보드: "다음 주 작전" + 승급 라인까지 6계단, 평균 +0.9점.

## 7. 시연용 데이터 (한 운전자, 한 시즌)

모든 시안은 같은 가상 운전자 "나"(아이오닉 5, 부산, 11월 시즌 골드 리그 397명)를 기준으로 한다.
시즌은 11월 1일~30일. 화면마다 기준 시점이 다르며, 아래 표의 시점 값을 그대로 쓴다.

일별 트립 점수 (모두 70점 이상, 수요일은 운전 안 함):

| 날짜 | 11/1 토 | 11/2 일 | 11/3 월 | 11/4 화 | 11/5 수 | 11/6 목 | 11/7 금 | 11/8 토 | 11/9 일 |
|---|---|---|---|---|---|---|---|---|---|
| 점수 | 88 | 89 | 84 | 88 | 휴식 | 90 | 92 | 86 | 93 |
| 시즌 순위 | | | P131 | P130 | P130 | P128 | P125 | P126 | P125 |
| 연속 기록 | | | | | | 12일 | 13일 | 14일 | 15일 |

| 화면 | 기준 시점 | 쓰는 값 |
|---|---|---|
| 주행 중 | 11/7 금 주행 중 | 11.2 / 18.4km, 목적지 해운대, "70점 넘기면 연속 13일째" |
| 결과 카드 (이긴 날) | 11/7 금 주차 직후 | 92점, 18.4km, P128 → P125 ▲3, 연속 13일, 시즌 평균 88.5 |
| 리그 순위 | 11/9 일 | P125, 시즌 평균 88.8, "21일 남음", 승급 라인까지 6계단 · 0.9점 |
| 주간 리포트 | 11/9 일 | 주간 평균 88.8 (지난주 85.7, +3.1), P131 → P125 ▲6 |

- 시즌 평균 = 시즌 트립 점수의 평균. 11/7 기준 (88+89+84+88+90+92)/6 = 88.5, 11/9 기준 여기에 86·93을 더해 88.8.
- 주간 평균 = (84+88+90+92+86+93)/6 = 88.8.
- 승급 라인 = 397명 × 30% ≈ P119, 시즌 평균 89.7 → 나와 6계단, 0.9점 차.
- 결과 카드와 리그 화면의 이웃 운전자 점수는 각 기준 시점의 내 시즌 평균에 맞춰 빌더가 정한다.

**아쉬운 날 결과 카드는 별도 시나리오다.** 같은 운전자의 다른 날(64점, P125 → P126, 연속 기록 끊김)로,
주간 리포트의 한 주와 이어지지 않는다. 제출물에서 "다른 날의 예시"임이 드러나게 표기한다.

가상 운전자 닉네임은 사용자가 직접 지은 것처럼 보이는 별명으로 채우고, 실존 인물로 오해될 이름은 쓰지 않는다 (예: 깜빡이장인, 해운대드라이버).

## 9. 빌더에게 맡기는 것

- 각 화면의 세부 간격, 글자 크기, 아이콘 모양.
- 차종 실루엣의 세부 선 (비율과 Z 라인은 지킬 것).
