# 밤샘 개선 계획 (2026-11-08, 완료)

사용자가 자는 동안 앱을 검토하고 고치며, 남은 기능을 차례로 추가한다.

**브랜치:** `claude/overnight-polish` (`claude/low-card-layout`에서 시작)

## 하지 않는 것

아침에 사용자 확인을 받을 일이다.

- `main` 병합, GitHub push, 저장소 public 전환, 이메일 제출, 숏폼 게시
- 기획서 서명본 교체 (앱 변경이 많으면 초안만 만든다)
- 점수 산식, 승급·강등 규칙, 포인트 배율처럼 사용자가 정한 값 변경

## 순서

1. **검토:** 서브에이전트 3명이 읽기 전용으로 코드 버그, 성능, UI·UX·에셋을 본다. 에뮬레이터는 메인 세션만 쓴다.
2. **수정:** 찾은 문제를 영향이 큰 순서로 고친다. 로직은 실패하는 테스트부터 쓴다.
3. **기능 추가:** 안전 가이드 하나로 묶는다.
   - 재난 상황 시 운전자 수칙, 상황별 주의사항, 초보 운전자 꿀팁
   - 내용은 공식 기관 자료로 확인하고 출처를 앱에 표시한다. 사람의 안전이 걸린 내용이라 확인되지 않은 문구는 넣지 않는다.
   - 주행 중에는 열지 않는다. 다만 재난 수칙의 주행 중 음성 안내는 범위 밖이다.
4. **에셋:** 플래티넘 벨트 재생성, 가이드 아이콘, 빈 배경 보강.
5. **성능·안정성:** 에뮬레이터에서 메모리, 화면 전환, 반복 진입을 확인한다.
6. **마무리:** 전체 코드 검토, 테스트, 에뮬레이터 회귀 시험, 기록, 아침 보고서.

## 각 단계 완료 조건

- 단위 테스트와 `assembleDebug` 통과
- 바뀐 화면은 에뮬레이터 캡처를 직접 본다
- 시험 트립과 날짜는 되돌린다
- 작은 커밋으로 남기고 `docs/app-dev-log.md`에 기록한다

## 지키는 규칙

`AGENTS.md`를 따른다. 주행 중 점수 화면 금지, 빨강은 출발 신호등에만, 아쉬운 날은 혼내지 않는 말투, 화면별 파일 분리, 저장소에 실명 금지.
