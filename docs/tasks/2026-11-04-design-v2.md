## 디자인 v2 요약 ("레이싱 중계 업그레이드")
- 글꼴: 한글 Pretendard(700/800/900), 숫자 Saira Condensed 800 기울임(합성 기울임 약 -10°). Black Han Sans는 v2에서 안 씀. Pretendard는 OFL — `res/font`에 static TTF 추가(라이선스 파일도 `app/src/main/assets/licenses/`).
- 색 토큰(`tokens.css :root`): asphalt #24272C, asphalt-deep #1B1E23, cell #2E3238, white #F2F1EC, grey #A3A9B2, yellow #FFC52E, red #D42232, gold #E3B24A, line 흰색 10%.
- 큰 점수 숫자 = 금속 질감(위→아래 #FFFFFF → #ECEAE3 46% → #A9A7A0 52% → #F5F4EF, LinearGradient Shader + 그림자). 아쉬운 날은 회색 금속(`.metal.dull`).
- 반투명 패널(`.glass`): 위→아래 흰 9% → 2.5% + 1dp 흰 10% 테두리 + 아래 그림자.
- 순위 행: skewX -10°, glass 바탕, 내 줄은 노랑 그라데이션(#FFDB6E → #FFC52E → #F2B312) + 노란 번짐 그림자.
- 배경: 기존 아스팔트 노이즈 + 방사 조명 + 비스듬한 노란 빛줄기(104°, 알파 7%).
- 경로: 회색 노면 아래 검은 35% 그림자 경로(8dp 아래로).
- 메인 캐릭터 "레이스 엔지니어"(헬멧, 바이저 LED 눈, 매트한 게임 화풍): `mockups/character/png/` 엄지(thumbs-up)·피트보드(pit-board)·무전(radio)·축하(celebrate)·격려(encourage)·얼굴(face). `res/drawable-nodpi/`에 webp 또는 png로 넣기.
  - 이긴 날: 엄지 포즈 + "팀 라디오 · 레이스 엔지니어" 말풍선.
  - 아쉬운 날: 피트보드 포즈, 보드 안에 "깜빡이!" 같은 한 단어(글자는 앱이 그림 위에 그림, 이미지엔 글자 없음). 피트 보드 카드 머리에 얼굴 동그라미.
  - 리플레이·리포트: 하단 띠에 얼굴 동그라미.
  - **주행 중 화면에는 캐릭터 절대 없음.** 애니메이션도 없음.

## 할 일 (항목마다 커밋 하나, 우선순위 순)
1. 글꼴·색 토큰 교체 (Pretendard 추가, colors.xml에 v2 토큰, 금지: 하드코딩 색).
2. 공용 Drawable/View: glass 패널, skew 행(기존 평행사변형 Drawable 재사용·확장), 금속 숫자 TextView(Shader), 팀 라디오 말풍선, 얼굴 동그라미.
3. 이긴 날 결과 카드 (`mockups/result-win.html`) — 캐릭터 포함.
4. 아쉬운 날 결과 카드 (`result-low.html`) — 빨강 금지, 피트보드 캐릭터.
5. 리그 (`league.html`), 6. 리플레이 (`replay.html`), 7. 주간 리포트 (`report.html`), 8. 주행 중 (`driving.html`, 캐릭터·애니메이션 없음).
10. **주행 중 날씨 배경** (사용자 요청 2026-11-04, 데이터 = 차량 신호로 결정) — 시안 `driving.html?w=sun|rain|snow|night`, PNG `mockups/png/5-driving.png`(맑음)·`5b-driving-rain.png`·`5c-driving-snow.png`·`5d-driving-night.png`.
   - 판정은 `core/`가 아닌 별도 순수 함수 + 단위 테스트: 와이퍼 작동 → 비, 외기온도 0℃ 이하 + 와이퍼 → 눈, 전조등 켜짐 또는 해 진 뒤 → 밤, 그 밖 → 맑음. 신호는 Pleos Vehicle State(라이트·공조 등)나 CarPropertyManager(`WINDSHIELD_WIPERS_STATE`, `ENV_OUTSIDE_TEMPERATURE`, `HEADLIGHTS_STATE`)에서 지원 여부를 확인(`checkXxxCapabilities`)하고 쓸 수 있는 것만 씀. 에뮬레이터에서 안 되는 신호는 시연 모드 값으로 대체하고 로그에 기록.
   - **정지 그림만**: 빗줄기·눈송이·별은 고정 시드로 한 번 그린 비트맵/Drawable. 애니메이션·입자 움직임·버튼 금지(예전 WeatherAmbientView는 이 이유로 삭제됨). 날씨가 바뀔 때만 교체, 1분에 한 번 이하.
   - 글자·트랙 영역(시안 `clear()` 범위)은 비움. "주행 기록 중 · 비"처럼 날씨 이름 한 단어만 표시.
   - 기획서와 맞추기 위해 사용한 신호 이름을 `docs/app-dev-log.md`에 적어 둘 것(Claude가 기획서 반영).
9. (여유 있으면) 캐릭터 등장 연출: 결과 카드가 뜰 때 캐릭터가 아래에서 살짝 올라오는 1회 ObjectAnimator(300ms 이내, P단에서만, onPause 정지). 반복 애니메이션 금지.

## 지킬 것
- 기존 불꽃/비 효과는 유지하되 점수를 덮지 않게(polish 5번 규칙 유지).
- 글씨 24sp 이상, 누르는 영역 76dp 이상, 대비 4.5:1. 아쉬운 날 빨강 금지.
- 점수·리그 계산(`core/`) 건드리지 않음. 저장소에 실명·연락처·이메일·소속 금지.
- 애니메이션 30fps 상한, 화면 안 보이면 정지. 주행 중 CarUxRestrictions 준수.
